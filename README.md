# Geospatial Analysis and ML-based AQI Prediction for Delhi

## 📌 Project Overview
This project analyzes Delhi's Air Quality Index (AQI) using Machine Learning and
Geospatial Visualization techniques.

## 🔍 Techniques Used
- Exploratory Data Analysis (EDA)
- Supervised Learning (Random Forest, KNN, Logistic Regression, SVM)
- Unsupervised Learning (K-Means, DBSCAN, Hierarchical Clustering)
- PCA & Dimensionality Reduction
- Folium-based AQI Map Visualization

## 🏆 Best Model
Random Forest Classifier – 95.13% accuracy

## 📊 Tools & Libraries
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Folium
